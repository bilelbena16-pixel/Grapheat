# La Boîte à Poulet — kit du logo

Logo principal : **version empilée** (icône boîte-poule au-dessus du nom). Couleurs : rouge `#E1251B`, noir `#141414`, blanc.

| Dossier | Contenu | Pour qui / quoi |
|---|---|---|
| `logo/` | Fichiers vectoriels SVG : empilé, horizontal, icône, texte seul — en `couleur`, `inverse` (fond noir), `noir`, `blanc`, `rouge` ; tuiles rouge/noire | Imprimeur, enseigniste, site web |
| `png/` | Les mêmes en PNG transparent (2000 px, icônes 1024 px) | Word, PowerPoint, Canva, réseaux |
| `web/` | `favicon.ico`, `favicon.svg`, icônes 16→512 px, `apple-touch-icon.png`, `maskable-512.png`, `site.webmanifest`, `head-snippet.html` | Développeur du site |
| `reseaux-sociaux/` | Photo de profil 1080 (tient dans le cercle), couverture Facebook 1640×624, story 1080×1920, bannière 1920×1080 | Instagram, Facebook, Uber Eats, Deliveroo |
| `maquettes/` | Emballages (boîte, sac kraft, gobelet) et devanture | Présentation, devis fournisseurs |
| `guide-utilisation.pdf` / `.png` | Règles : versions, zone de protection, tailles minimum, couleurs, fonds, interdits | Toute personne qui utilise le logo |

## À faire avant d'utiliser le logo publiquement
1. **Acheter la licence commerciale de la police Craze** (Pian45 Studio — pian45.gumroad.com). Le fichier fourni est « personal use only ».
2. Faire une **recherche d'antériorité** (INPI / EUIPO) sur le nom et le logo avant de les déposer.
3. Valider les **références Pantone / CMJN** avec l'imprimeur sur nuancier (valeurs approchées dans le guide).

Les SVG sont entièrement vectorisés (aucune police à installer) ; l'œil et la ligne du couvercle sont de vrais évidements, donc le logo fonctionne en une couleur, en découpe vinyle et en gravure.
